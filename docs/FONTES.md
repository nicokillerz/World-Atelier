# Fontes incluídas

Embutidas em `src/renderer/fonts/` (subconjunto latino, via pacotes `@fontsource/*`), todas sob a
**SIL Open Font License 1.1** (https://openfontlicense.org): Cinzel, Cinzel Decorative, Cormorant Garamond,
Playfair Display, Almendra, UnifrakturCook, Philosopher, Bebas Neue e MedievalSharp.
Para trocar ou adicionar fontes, coloque o `.woff2` na pasta e declare-o em `fonts/fonts.css`.
