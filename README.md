# 🌎 World Atelier

**Your own little workshop for creating and organizing fictional worlds.**

World Atelier is a free, open-source desktop application designed to help writers, worldbuilders, and creative minds organize their fictional universes.

Whether you're creating an entire fantasy world, developing original characters, writing interconnected stories, or simply keeping track of all those little details that would otherwise get lost in a hundred different documents, World Atelier aims to give you one place to bring everything together.

## ✨ Why World Atelier?

This project started with a simple, personal desire: I wanted a place where I could organize all my stories, characters, worlds, and ideas without having to rely on dozens of scattered files.

I couldn't quite find what I was looking for, so I decided to make it myself.

Eventually, I thought: why keep it to myself?

World Atelier is now being shared for free, as an open-source project, so anyone can use it, customize it, modify its code, and make it their own.

## 🧰 Features

World Atelier offers a variety of tools to help organize your creative projects, including:

- **World Management** — Create and organize multiple fictional worlds and subworlds.
- **Character Profiles** — Keep track of your original characters and their details.
- **Stories** — Organize stories and connect them to your fictional worlds.
- **Locations** — Document places, regions, and important locations.
- **Lore & Wiki** — Build your own encyclopedia of worldbuilding information.
- **Bestiary** — Register species, creatures, and other beings.
- **Maps** — Keep track of maps related to your worlds.
- **Gallery** — Organize visual references and images.
- **Items & Inventory** — Keep track of objects, resources, and other belongings.
- **Timeline & Calendar** — Organize events, dates, and important moments.
- **And more!**

- Available in English and Portuguese (Brazilian)

*Features and details may change as development continues.*

## 🧪 Made with AI, Refined by Human Frustration

Let's be honest: World Atelier was vibe-coded.

## 💻 Installation

**Windows**

Download the latest Windows installer from the project's Releases page.

Run the installer and follow the instructions.

*Installation files and release downloads will be added when the project is ready for its first public release.*

**Running from source**

Requirements:
- Node.js
- npm

Clone the repository:

```bash
git clone https://github.com/nicokillerz/world-atelier.git
cd world-atelier
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm start
```
